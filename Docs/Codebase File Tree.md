### `.md` double-click path (separate from right-click)

```
[user double-clicks .md in File Explorer]
        │
        │  HKCR\.md → ObsidianMD
        │  HKCR\ObsidianMD\shell\open\command
        │  → "build\open_md_in_obsidian.bat" "%1"
        ▼
open_md_in_obsidian.bat:
        ├─ src       = %~1
        ├─ leaf      = %~nx1
        ├─ leaf_noext = %~n1
        ├─ mkdir Temp Obsidian Vault + .obsidian marker
        ├─ if exists → dedup: "<noext> (2).md", "(3).md", ...
        ├─ copy /Y src → temp_file
        ├─ recompute final_leaf, final_leaf_noext from temp_file (post-dedup)
        ├─ set _OBS_LEAF=final_leaf
        ├─ powershell -Command Start-Process(
        │      "obsidian://open?vault=" + EscapeDataString("Temp Obsidian Vault")
        │      + "&file=" + EscapeDataString($env:_OBS_LEAF))
        └─ start /B obs_watcher.exe <temp_file> <final_leaf_noext> "Temp Obsidian Vault"
                          │
                          ▼
                Obsidian launches (vault opens, file lookup CURRENTLY MISSES)
                          │
                          ▼
                user edits + closes Obsidian window
                          │
                          ▼
obs_watcher.exe:
        ├─ SetWinEventHook EVENT_OBJECT_DESTROY..EVENT_OBJECT_SHOW
        ├─ EnumWindows catch-up
        ├─ EVENT_OBJECT_SHOW + TitleMatches(leaf, vault) → g_target = hwnd
        ├─ EVENT_OBJECT_DESTROY for g_target → PostQuitMessage
        └─ DeleteFileW(temp_file); exit
```
